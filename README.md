## 📌 ภาพรวมโปรเจกต์ (Project Overview)

[เขียนอธิบายรายละเอียดเกมเพิ่มเติม 2-3 บรรทัด เช่น พลอตเรื่องสั้น ๆ เป้าหมายของผู้เล่นคืออะไร พัฒนาขึ้นมาเนื่องในโอกาสอะไร เช่น Project ส่งอาจารย์, ร่วมงาน Game Jam หรือทำเพื่อฝึกฝนทักษะ]

*   **🎮 แนวเกม (Genre):** 2D Game Puzzle-Platformer Horror Adventure เกมผจญภัยไขปริศนาระทึกขวัญ 
*   **🖥️ แพลตฟอร์ม (Platform):** PC (Windows/Mac) Web Browser
*   **👥 ทีมพัฒนา (Players):** Single-player

## 🚀 การติดตั้งและการเปิดใช้งาน (Installation & Setup)

### สำหรับผู้เล่น (Play the Game)
👉 สามารถดาวน์โหลดตัวเกมเวอร์ชันสำเร็จรูป (.exe / .apk) ไปเล่นได้ทันทีที่: **[ใส่ลิงก์ดาวน์โหลด เช่น Itch.io หรือ GitHub Releases]**

### สำหรับนักพัฒนา (For Developers)
หากต้องการนำโค้ดไปเปิดในโปรแกรมพัฒนาเกม ให้ทำตามขั้นตอนดังนี้:

1. Clone โปรเจกต์นี้ลงเครื่องของคุณ:
   ```bash
   git clone https://github.com[ชื่อผู้ใช้ของคุณ]/[ชื่อคลังเก็บโค้ดของคุณ].git
   ```
2. เปิดโปรแกรม **[ใส่ชื่อ Engine เช่น Unity Hub]**
3. เลือก **Add** หรือ **Open** แล้วเลือกโฟลเดอร์โปรเจกต์ที่เพิ่ง Clone ไป
4. เปิด Scene หลักที่ตั้งอยู่ในโฟลเดอร์ `Assets/Scenes/[ชื่อ Scene หลัก].unity`

# Little Nightmares II - Main Menu (Godot 4.3)
https://sitthiphongn-sudo.github.io/The_littleHam/
โปรเจกต์นี้เป็นจุดเริ่มต้นของหน้าเมนูหลัก สไตล์ Little Nightmares II ตามภาพตัวอย่าง
ประกอบด้วย:

- `project.godot` — ไฟล์โปรเจกต์ Godot (ตั้งค่า resolution 1222x650, main scene = MainMenu)
- `scenes/MainMenu.tscn` — ฉากเมนูหลัก
- `scripts/MainMenu.gd` — สคริปต์คุมการเลือกเมนู (เมาส์ hover / คีย์บอร์ด / จอย) และ fade-in

## วิธีเปิดโปรเจกต์
1. เปิด Godot 4.3 ขึ้นไป
2. กด "Import" แล้วเลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
3. เปิดฉาก `scenes/MainMenu.tscn` แล้วกด Run (F6) เพื่อดูผล

## สิ่งที่ควรเพิ่มเองเพื่อให้เหมือนต้นฉบับมากขึ้น

### 1. ฟอนต์ (สำคัญที่สุด)
ตัวอักษรหัวเรื่อง "NIGHTMARES" ในเกมจริงเป็นฟอนต์ลายมือ/แกะสลักเฉพาะตัว
ผมยังไม่ได้ใส่ฟอนต์ให้ เพราะไม่มีไฟล์ฟอนต์แนบมา แนะนำฟอนต์ฟรีที่ให้ฟีล
ใกล้เคียง (โหลดได้จาก Google Fonts):
- **Nanum Brush Script** หรือ **Caveat** (ลายมือ)
- **Butcherman** (แนวสยองขวัญ ตัวหนา)

ขั้นตอน:
1. โหลดไฟล์ `.ttf` มาวางไว้ที่ `assets/fonts/`
2. ในฉาก `MainMenu.tscn` เลือก Label แต่ละอัน (LittleLabel, NightmaresLabel, RomanLabel)
   แล้วไปที่ Inspector > Theme Overrides > Fonts > Font ลากไฟล์ฟอนต์มาใส่
3. ทำแบบเดียวกันกับปุ่มเมนูทั้ง 4 ปุ่ม เพื่อให้ตัวอักษรเมนูเป็นลายมือด้วย

### 2. ภาพพื้นหลัง
ตอนนี้พื้นหลังเป็น gradient สีน้ำเงินเข้มธรรมดา (ไล่จากฟ้าอมเทาด้านบนไปดำสนิทด้านล่าง)
เพื่อให้เหมือนภาพตัวอย่าง (ตึกโครงร่าง, หมอก) ให้:
1. หารูปพื้นหลังแนว dark blue city silhouette + fog (หรือ render ฉากจริงจาก 3D)
2. ลากไฟล์รูปมาใส่ที่ node `BackgroundArt` (Inspector > Texture)
3. ปรับ `modulate` ของ `BackgroundArt` ให้จางลงถ้าต้องการให้กลืนกับพื้นหลัง gradient

### 3. Vignette (ขอบจอมืด)
Node `Vignette` เตรียมไว้ให้แล้วแต่ยังไม่มีเอฟเฟกต์ ถ้าต้องการขอบจอมืดแบบในภาพ
แนะนำใช้ Shader แบบง่าย ๆ ใส่ใน CanvasItem Material ของ node นี้ (บอกผมได้ถ้าอยากให้เขียน shader ให้)

### 4. เสียง/ดนตรีประกอบ
ยังไม่ได้ใส่ AudioStreamPlayer ให้ ถ้าต้องการเพลงเปิดเกมคลอเบา ๆ บอกได้เลย
จะเพิ่ม node และโค้ด fade-in เสียงให้

## การควบคุมที่ทำไว้แล้ว
- เลื่อนเมาส์ชี้ปุ่ม → ปุ่มนั้นสว่างขึ้นเป็นสีขาว ปุ่มอื่นจางลง (เหมือนต้นฉบับ)
- ปุ่มลูกศร/D-pad (Godot จัดการ Focus ให้อัตโนมัติผ่าน VBoxContainer)
- ปุ่มที่เลือกอยู่จะขยับไปทางขวาเล็กน้อยเป็นแอนิเมชัน
- เมนูทั้งหมด fade-in ตอนเข้าฉาก

## ขั้นต่อไปที่แนะนำ
- เพิ่มฉาก transition ตอนกด "New Game" (fade to black แล้วโหลดฉากเกม)
- เพิ่มเมนูย่อยของ Settings (เสียง, ภาษา, ความละเอียดจอ)
- ถ้าต้องการ parallax เบา ๆ ของพื้นหลังตอนขยับเมาส์ บอกได้ ทำเพิ่มให้ได้เลย

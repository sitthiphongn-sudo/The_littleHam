## 📌 ภาพรวมโปรเจกต์ (Project Overview)
เกม The Little Ham LABORATORY ESCAPE ผู้เล่นรับบทเป็นหนูแฮมสเตอร์ตัวเล็ก ซึ่งถูกจับมาเป็นสัตว์ทดลองภายในห้องปฏิบัติการลึกลับแห่งหนึ่ง วันหนึ่งเกิดเหตุการณ์บางอย่างทำให้ระบบกักกันเปิดออก Hamster จึงต้องพยายามหลบหนีออกจากห้องทดลองแห่งนี้ ระหว่างทาง ผู้เล่นจะต้องสำรวจสภาพแวดล้อม สังเกตสิ่งรอบตัว แก้ปริศนา และหลีกเลี่ยงอันตรายต่างๆ ตัวเกมเป็นหนึ่งใน project midterm ในรายวิชา Computer Game Development 


*   **🎮 แนวเกม (Genre):** 2D Game Puzzle-Platformer Horror Adventure เกมผจญภัยไขปริศนาระทึกขวัญ 
*   **🖥️ แพลตฟอร์ม (Platform):** PC (Windows/Mac) Web Browser
*   **👥 ทีมพัฒนา (Players):** Single-player

## ✨ ฟีเจอร์เด่น (Key Features)

*   **[ระบบที่ 1]:** [อธิบายสั้น ๆ เช่น ระบบต่อสู้ Combo ที่ลื่นไหล]
*   **[ระบบที่ 2]:** [เช่น ศัตรูมี AI คอยเดินลาดตระเวนและไล่ตามผู้เล่น]
*   **[ระบบที่ 3]:** [เช่น ด่านการเล่นที่มีกลไกปริศนาแตกต่างกัน 3 ด่าน]

## 🎮 ปุ่มควบคุม & วิธีเล่น (Controls & How to Play)

### วิธีการควบคุม (Controls)
*   **เคลื่อนที่ (Move):** `W` `A` `S` `D` หรือ `ปุ่มลูกศร`
*   **กระโดด (Jump):** `Spacebar`
*   **โจมตี (Attack):** `Click ซ้าย`
*   **ทำภารกิจ(ณnteract)** `E`
*   **หยุดเกม (Pause):** `Esc`

### วิธีการเล่น (How to Play)
1. [เป้าหมายที่ 1 เช่น เดินสำรวจด่านเพื่อเก็บกุญแจให้ครบ 3 ดอก]
2. [เป้าหมายที่ 2 เช่น หลบหลีกศัตรูและกับดักระหว่างทาง]
3. [เป้าหมายที่ 3 เช่น เข้าเส้นชัยที่ประตูท้ายด่านเพื่อผ่านไปยังระดับต่อไป]
